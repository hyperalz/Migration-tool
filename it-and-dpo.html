What MapBridge reads and stores

✓ Reads

Field names (like employee_id or start_date), field types (like number or date), allowed values (like Y and N), and field notes from your supplier.

✗ Never reads

Employee names, salaries, addresses, or any other personal data. The read-only tool for SQL Server and Oracle only queries the system catalog (the list of tables and fields), not the tables themselves.

Where it is stored

In the web browser on your computer. Not on a server. When you close the browser, it stays on your computer unless you clear your browser data.

What the AI suggestion mode sends

If you use the built-in matcher

Nothing is sent anywhere. It runs entirely in your web browser.

If you use your own AI API key

Only field names, types, and notes are sent to the AI service you choose (like OpenAI or Azure). No employee names, salaries, or any personal data.

Your API key is stored in your web browser only. It is never sent to us.

The read-only connector

A Python script that your IT team runs inside your network for the duration of the migration, then deletes.

What it does

Queries information_schema or system catalogs to get table and column names, types, and constraints.

Writes a JSON file with the list of fields.

What it needs

SQL Server: A read-only database user with VIEW DEFINITION permission.

Oracle: A user with SELECT on ALL_TABLES, ALL_TAB_COLUMNS.

What it never does

Query user tables. Read employee names, salaries or other personal data. Send data anywhere. Listen on a port.

Data protection impact assessment

Questions DPOs ask and our answers.

What personal data does MapBridge process?

None. MapBridge processes metadata: field names, field types, allowed values, and field descriptions. It does not process names, salaries, addresses, or any other personal data.

Where is the data stored?

In the web browser on the user's computer, using browser localStorage. No data is sent to a server or stored in the cloud.

Who has access to the data?

Only the person using that web browser. There is no server, no database, and no shared workspace in the current version.

What happens to the data after the migration?

It stays in the browser unless the user clears their browser data. We recommend exporting the final signed-off report as a PDF or CSV, then clearing the browser data.

Does the AI mode send personal data?

No. The AI mode only sends field names, types, and notes. It does not send employee names, salaries, or any other personal data. The AI mode is optional and requires the user's own API key.

What permissions does the read-only connector need?

SQL Server: VIEW DEFINITION on the database. Oracle: SELECT on ALL_TABLES, ALL_TAB_COLUMNS, ALL_CONSTRAINTS. It queries the system catalog only, never user tables.
