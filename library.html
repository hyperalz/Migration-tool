What the library covers

An area has system lists when the library holds a real system's fields for it. Planned lists come from public sources we are working through.

Two kinds of list

System list

One product's own fields, such as a finance or housing system. This is what you match against in a migration.

Each list holds the core fields most often moved, not every field in the system. Big systems have many more, most rarely used.

From the supplier's public documentation, or sent and checked by the supplier.

Statutory return

The fields any system in a service area must be able to send to government, such as a school census. A starting point and a checklist: your returns still have to work after the move.

From government standards. A real system has many more fields.

    How lists get here

    • Statutory return lists: from standards published by government.
    • System lists: from suppliers' public documentation, field names only and linked to the source.
    • System lists: from suppliers who send us their list and check it.

    We write the notes ourselves and never copy a supplier's files. A council's own field list joins the library only with its written permission.

    For councils and schools

    Use a ready list when you start a project in MapBridge. If the system you are leaving or moving to is not here, tell us. We use requests to decide what to add next.
